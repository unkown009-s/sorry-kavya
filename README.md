# Sorry, Kavya

A small animated apology website. No installs, no build step.

## Run it in VS Code

1. Unzip the folder and open it in VS Code (File > Open Folder).
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and choose **Open with Live Server**.

You can also just double-click `index.html` to open it in a browser.
The fonts load from Google Fonts, so you need internet the first time.

## Make it yours

Open `script.js`. Everything you need to change is in the `CONFIG` block at the top:

- `from`: put your name here (it shows at the end of the letter and on the last screen).
- `letter`: the lines that get typed out. Rewrite them in your own words, and add what you
  actually want to say once you know what happened.
- `promises`: the three flip cards. Change the titles and text so they are real promises.

Colors are at the top of `style.css` (the `:root` block).

## Send it to her

A file on your computer can't be opened from her phone. To share it as a link:

- Drag the whole folder onto **https://app.netlify.com/drop** and you get a link in seconds, or
- Push it to GitHub and turn on GitHub Pages.

## Tip

The page says you don't know what went wrong. That's honest, and it's the right
thing to say. A message like "Can we talk? I want to understand" along with the link will go further than the page alone.
